# Copy — 数据驱动的"材料配比"小游戏

用 UE5(5.3,纯蓝图)做的一个小游戏原型:按配方挑选建筑材料、观察结果,支持「改造前 / 改造后」两套场景对比。

## 实现要点
- **数据表驱动**:材料用 `Enum + Struct + DataTable` 定义(名称、类型、配比、效果),界面与玩法逻辑都从数据表读,新增材料只加一行数据。
- **before / after 双场景**:同一关卡的两种状态,玩家操作后切换到"改造后"场景对比结果。
- **UI 反馈**:材料条形表、目标提示、进度条与多级警告提示(材料不足 / 配比错误等)分层给出反馈。

## 目录
```
Content/
  Blueprint/     关卡与游戏模式蓝图(before / after)
  MaterialData/  E_MaterialType + S_MaterialData + DT_MaterialData
  UI/            条形表、材料表、目标与警告提示
  image/         材料与界面素材
```
